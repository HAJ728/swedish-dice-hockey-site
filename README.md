# Swedish Dice Hockey — website

The support and privacy pages for Swedish Dice Hockey, the notepad hockey game of
the eighties built as a real app for Mac, iPad and iPhone.

* [App Store](https://apps.apple.com/app/id6806634069) — App Store-id 6806634069, same listing for iPhone, iPad and Mac
* [Support](https://haj728.github.io/swedish-dice-hockey-site/support.html)
* [Privacy Policy](https://haj728.github.io/swedish-dice-hockey-site/privacy.html)

The pages live in the app's own repository, under `Site/`, and are copied to the
site repository by hand. Editing a file there without doing the same here means
the next copy quietly overwrites it.

The pages are plain HTML with no build step, no scripts and no external requests.
They are in English because the App Store listing is; the app itself is in Swedish.

**When something in the app changes, these pages need reading again.** The support
page names buttons — *Säkerhetskopiera bok…*, *Återställ säkerhetskopia…*, the team
button — and the privacy page describes what a book contains and where it goes.
A renamed button or a new permission makes them wrong.
